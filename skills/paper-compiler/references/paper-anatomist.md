# paper-anatomist — 高被引用論文の型（体裁エビデンス集）

paper-compiler の **write（タイトル・アブスト・骨格の生成時）** と **audit（体裁系項目の根拠提示時）** から参照する。各項目は大規模計量書誌研究のエビデンスに基づく（出典・詳細：`docs/PaperAnatomy_HighCitation_Patterns_JA.md`。venue 実測での上書きは `scripts/paper-structure-analyzer/`）。

**E1 実測による較正（2026-08-31・TKDE/PVLDB/DMKD 2,814本）**：同一 venue 内の被引用層を分けるのは **R（参考文献）のみ**（Price指数 δ=0.32・本数 0.31・参照先インパクト 0.30）。T・A は層内では negligible＝**venue 間で効く入場券**として扱う。指導の重心は R に置く。詳細は `docs/PaperAnatomy_HighCitation_Patterns_JA.md` §E1。

**大原則**：これらは相関で効果量は小さい（r < ±0.2）。被引用の主因は内容。型は「読まれ・理解され・引用しやすくする」ための下限整備であり、ゲーミング（意図的な難読化等）は行わない。指導の目標層は top 1% ではなく **top 10%（venue-year 内）**：型の説明力が最も高いのはこの層への移行である。

## T：タイトル

| ID | チェック | 根拠の要旨 |
|---|---|---|
| T-01 | トップ venue 狙いなら **10〜14語以内**か | 高被引用層で短タイトル優位（Letchford+2015 τ≈−0.07；経済学でチーム統制後も同符号）。**非トップ誌では逆に情報量が利く**（Sienkiewicz & Altmann 2016）— venue tier で切替 |
| T-02 | `手法固有名: 何を可能にするか` の**コロン2部構成**を検討したか | コロン付きタイトルは被引用にプラス（Jacques & Sebire 2010; Buter & van Raan 2011） |
| T-03 | **疑問形**は venue の直近採録実績を確認してから | 古典的には引用マイナス（DL は増える）だが CS では +16%（Fiala+2021）— 分野反転リスト対象 |
| T-04 | 不必要な限定語（国名・「for X」「applied to Y」「case study」等の適用限定句）を落としたか | 一般化タイトルが引用優位（Fox & Burns 2015）。国名は低被引用の劇的予測因子（低被引用 Lancet の1/3超に出現・高被引用群はゼロ）。適用限定は Abstract・Introduction へ。応用系会議・地域誌では例外可（一般性仮説：レポート§2bis） |
| T-05 | 具体的な手法・デザイン語（例: randomized, meta-analysis, 手法固有名）が入っているか | 高被引用群に頻出。survey / questionnaire / national 等の記述語のみは低被引用群のパターン |

## A：アブストラクト

| ID | チェック | 根拠の要旨 |
|---|---|---|
| A-01 | **Hyland 5ムーブ**（導入→目的→方法→結果→結論）を全て被覆しているか。7文法の文1–2/3/4–5/6/7 が各ムーブに対応 | 実証系では Results ムーブ出現率ほぼ100%。ムーブ完全被覆＝長め傾向が有利 |
| A-02 | **結果ムーブに数値**（改善幅・精度・効果量）が入っているか | 数値なし Results は T10 層でほぼ観察されない。岡先生の「数字に意味を与える」と接続 |
| A-03 | venue 語数上限の **85〜100%** を使っているか | 語数と被引用の正相関（多数）。切り詰めすぎない |
| A-04 | **統語は平易・語彙は正確**の分離を守っているか | 可読性スコアが低い（＝専門語彙が濃い）アブストが高被引用側という大規模知見があるが、因果不明・難読化は禁止。7文法の「閉世界・平易な統語」は文構造の規範であり語彙を薄める規範ではない |

## S：章構造・ラベル

| ID | チェック | 根拠の要旨 |
|---|---|---|
| S-01 | venue が **IMRaD 規範型か自由型か**を判定して骨格を選んだか（初期質問テーブル「venue（骨格）」） | 循環器 ≥92% IMRaD ラベル vs 計算言語学は標準構造なし — 分野で規範が全く違う |
| S-02 | 自由型 venue では**手法章の見出しに手法固有名**を使ったか | CS/AI トップ層の慣行。見出しが引用時の記憶フックになる |
| S-03 | **Limitations** の独立小節（または明示段落）があるか | 近年トップ venue で checklist 化が進行 |

## R：参考文献リスト

| ID | チェック | 根拠の要旨 |
|---|---|---|
| R-01 | 参照本数が venue の T10 層水準か（少なすぎないか） | 参照本数と被引用の正相関は最も再現性の高い知見の一つ |
| R-02 | **Price 指数（5年以内比率）**：AI/CS系 ≥0.6（理想0.7）、他分野は venue 実測+0.1 | 「7割・2020年以降」は記述的事実ではなく**高速分野向けの処方的目標**。Price ≥0.72 群は被引用の離陸が最速。E1 実測：T10 中央値 0.57 vs B 0.47（0.7 は T10 上位のみ） |
| R-03 | **直近2年**の文献を含むか | 離陸速度に効く。arXiv は preprint と明記の上で可（既存原則） |
| R-04 | 古典（創始文献・データ原典）を **recency のために削っていない**か | 古典比率は被引用と無関係（害にならない）。recency は残り枠で稼ぐ |
| R-05 | 方法・比較の**直接エンゲージ文献**と背景の**権威文献**の役割分担があるか | 高被引用論文の引用文脈分析より（束引用の背景文献化） |

## 分野反転リスト（venue 実測で上書きすべき特徴）

| 特徴 | 反転の内容 | 上書き方法 |
|---|---|---|
| タイトル長 | トップ誌：短が有利 ／ 非トップ誌：長が有利 | analyzer で venue の T10 中央値を測る |
| 疑問形タイトル | 医学系：不利 ／ CS・SE：有利 | 同上＋直近2年の採録タイトル目視 |
| アブスト可読性 | 多数分野：難読側が高被引用 ／ 社会科学：逆 | 規範としては「語彙は内容が決める」で固定 |
| 構造化アブスト | 医学系で規範 ／ CS では非標準 | venue 投稿規定に従う |

## A-05：LLM スタイル語の回避（v4 追加・候補規範）

| ID | チェック | 根拠の要旨 |
|---|---|---|
| A-05 | delve / intricate / meticulous / realm / pivotal / showcase / underscore / commendable / tapestry / testament 等の **LLM 特有スタイル語**を使っていないか | Kobak+2025：ChatGPT 後に急増した excess vocabulary。査読者・編集者に AI 生成の痕跡として認識されつつある。E1：2023 年に出現率 2 倍。7文法の「平易な統語・正確な語彙」と整合（ゲーミングではない） |

## audit との接続

audit（18項目）実行時、体裁系の指摘（タイトル・アブスト・参考文献）には本表の ID（T-01 等）を根拠として併記する。❌/⚠️ には必ず充足質問または下書き案を添える（スキル本則）。
